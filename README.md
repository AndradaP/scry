# The Shard

**Product teardowns powered by the best product minds.**

The Shard is an AI-powered product analysis tool that generates deep, structured teardowns of any product or feature — grounded in insights from Lenny Rachitsky's podcast and newsletter archive.

## What it does

**Generate a Teardown** — Enter any product or feature and get a full-stack analysis covering strategy, positioning, feature breakdown, growth model, design, and key insights. Every section draws on real frameworks and perspectives from world-class product, growth, design, and investing experts.

**Critique My Teardown** — Submit your own product teardown and get expert feedback on what you got right, what you missed, and how to sharpen your thinking.

Both modes include a chat interface for follow-up questions, grounded in the same expert corpus.

## Built with

- React + Vite
- Supabase (auth, Postgres, Edge Functions)
- Anthropic Claude API
- Lenny's Data (podcast transcripts + newsletter archive)
