Scoring Rubric

How every teardown actually gets scored: one deterministic layer, four judged dimensions. This is the mechanics — for the reasoning and bias vocabulary behind each choice, see the companion Learning Log.

01Two layers, on purpose

One layer can't hallucinate its own verdict. The other measures something no deterministic check can: whether the reasoning is actually good.

Layer 1 — Citation verification is not an LLM judgment. Every citation gets extracted by pattern-matching, then checked against the real archive (or checked for format-legitimacy, for web citations). It either finds the source or it doesn't.

Layer 2 — Four LLM-judged dimensions compare two outputs head-to-head. These are inherently softer — reasoning quality doesn't reduce to a lookup — so every dimension carries explicit countermeasures against known judge failure modes (below).

The core thesis question — does Scry's grounding hold up — should be answered primarily from Layer 1. Layer 2 explains how good the analysis is once grounding is trusted; it shouldn't carry the up-or-down call alone.

04How Grounded Insight Value is actually computed

  1. Extract every distinct strategic claim from each output independently.
  2. Dedupe — a separate judge call identifies which claims from each side are the same point made differently, so paraphrasing can't fake uniqueness. Only claims with no equivalent on the other side proceed.
  3. Classify groundedness for every surviving unique claim, programmatically, not judge-guessed: check the real archive first (same lookup citation-verification uses); if nothing matches, run a live web search fact-check.
  4. Score usefulness (1–5, judge-rated) for every claim — grounded or not. An ungrounded claim's usefulness is still needed, because it determines the size of the penalty below.
  5. Reduce to one score per arm.
validity by tier: // programmatic, not judge-guessed archive_verbatim = 5 archive_paraphrase = 3 web_corroborated = 4 ungrounded = 0 // contradicted, or no evidence found anywhere score(arm) = Σ (validity × usefulness) // for every grounded claim − Σ (usefulness × 3) // for every ungrounded claim — the penalty weight winner = higher score, unless |scoreA − scoreB| ≤ 2 // then: tie

The penalty weight (3) and tie threshold (2) are starting heuristics, not validated constants — tune once a full batch of real score distributions exists.

06Known open gaps — not fixed, flagged

Self-preference residual. The Claude judge backend uses claude-sonnet-4-5 — the same model that generated the claude_vanilla/claude_web arms it scores. Read a Claude-only verdict on those comparisons as provisional until Gemini's independent verdict exists for the same pair.

Lexical-only archive matching. Both citation-verification and Grounded Insight Value's groundedness check use word-overlap matching, not real semantic search. A claim marked "ungrounded" may be a genuine fabrication, or genuinely archive-sourced material worded too differently for the matcher to find. Deliberately not fixed pre-emptively — see the Learning Log's retrieval-techniques entry for why.

Inter-rater agreement not yet computed. Once Gemini is producing real results, comparing how often the two judges agree per dimension is a cheap, real reliability signal that doesn't exist yet.
